# Simon Says Game 🎮

A web-based Simon Says memory game built using **HTML, CSS, and JavaScript**. The game tests the player's memory by generating an increasingly long sequence of colors that must be repeated correctly.

## 🚀 Features

- Interactive gameplay
- Random color sequence generation
- Increasing difficulty with each level
- Score/Level tracking
- Responsive and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎯 How to Play

1. Press any key to start the game.
2. Watch the highlighted color carefully.
3. Repeat the sequence by clicking the colored buttons.
4. Each correct round adds one more color to the sequence.
5. The game ends when you click the wrong color.
